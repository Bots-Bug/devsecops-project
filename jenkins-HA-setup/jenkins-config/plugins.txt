# ─────────────────────────────────────────────────────
# PLUGINS TO AVOID (and why):
# ─────────────────────────────────────────────────────
# amazon-ec2          - Use Terraform for infra, not Jenkins
# blueocean           - Heavy, multiple plugins, often broken
# publish-over-ssh    - Insecure, use Pipeline SSH steps instead
# build-pipeline-plugin - Legacy, use Declarative Pipeline
# parameterized-trigger - Complex, use Pipeline directly
# rebuild             - Encourages bad practices
# thinBackup          - Replaced by EFS + AWS Backup strategy
# backup              - Same as above
# Any plugin with "free-style" focus - use Pipeline instead
